# Security Policy

FutureBridge AI follows privacy-by-design and security-by-design principles.

## Security Requirements

- Never commit API keys, passwords, tokens, or production credentials.
- Apply the principle of least privilege.
- Validate all external inputs.
- Protect student information and personal data.
- Avoid collecting unnecessary personal information.
- Treat retrieved documents as untrusted input.
- Maintain secure service-to-service communication.
- Regularly review dependencies for security vulnerabilities.

## Vulnerability Reporting

Security vulnerabilities should be reported privately to the repository owner.

Do not publish sensitive vulnerability details, credentials, or personal information in public issues.

## Supported Versions

The project is currently in early development and does not yet have a production release.
